# DevBlog
O nome é definido em lib/blog.mjs. Para publicar, acrescente um objeto ao array posts com slug único, title, description, category, date (YYYY-MM-DD), published: true, featured (opcional) e sections: [{heading, text, code}]. Mantenha published: false durante a revisão. Não publique dados privados. A primeira versão não exige credenciais nem serviços externos. A integração Notion deverá usar acesso somente no servidor e uma base editorial dedicada, mediante aprovação. Execute npm run lint, npm test e npm run build antes de publicar.

## Notion CMS
Create a read-only internal integration at https://www.notion.so/my-integrations and grant access only to the DevBlog database. Set NOTION_TOKEN and NOTION_DATA_SOURCE_ID (41b468ba-c2c7-817e-a178-000b322f1c1b) in server environment variables on Vercel; never prefix token with NEXT_PUBLIC_. Set Status to Publicado and provide a unique slug, category and publication date. Supported content: top-level headings, paragraphs, lists, quotes and code. Uploaded covers, nested blocks and rich formatting are not yet supported. CMS failures are surfaced rather than silently exposing drafts. Test in preview before merging. Supabase setup awaits organization confirmation.
